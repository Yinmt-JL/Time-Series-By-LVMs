## 一、思想及优势

LVMs 用于时间序列分析

核心思路是**将时间序列转换为图像**，再用**视觉模型**处理

LVMs 相对 LLMs 的 4 大核心优势


1. **数据特性更契合**：图像的连续像素序列，与时间序列的连续数值特性一致。已学习到趋势、周期、峰值等关键时序模式；
2. **天然支持多变量相关性建模**：部分成像方法可直接表征多变量时间序列，无需像 LLMs 那样假设变量独立，能显式编码变量间的关联。
3. **提示更友好、成本更低**：LLMs 处理时序数据时，需要将大量浮点数列转化为文本描述，容易受限于上下文长度，且 API 调用成本高；LVMs 直接处理图像，不存在这些问题。
4. **擅长长序列建模**：部分成像方法能对长时序进行紧凑编码，具备捕捉长期依赖关系的潜力。

---

## 二、单变量(UTS) 和 多变量(MTS)

### 单变量时间序列（UTS）:
包含**一个特征 / 变量**的时序数据（如单一股票的价格走势）

### 多变量时间序列（MTS）:
包含**多个关联特征**的时序数据（如某地区的气温、湿度、风速的时序变化）

## 三、Time Series To Image Transformation 分类

### (1) 折线图 (Line Plot)

**适配时序类型:** UTS、MTS

- 对于 MTS，两种成图方式：
  - 所有变量绘制在**同一张折线图**
  - 每个变量的单变量折线图单独生成，再拼接为**一张更大的组合图像**

**优势：**
- 支持**单 / 三通道生成**，适配多数视觉模型

**局限性：**
- 仅适用于**变量数量少**的 MTS（多变量易重叠失真）；

### (2) 热力图（Heatmap）

**适配时序类型:** UTS、MTS

- 对**MTS**：直接将 d×T 的 MTS 矩阵（d 为变量数，T 为时间步）转化为 d×T 的**单通道**热力图，是 MTS 成像的最直接方式
- 对**UTS**：需先做矩阵化处理，再生成热力图

**优势：**
- **对 UTS 和 MTS 适配性强**
- MTS 直接成像的最优方案

**局限性：**
- 变量的**排列顺序**会直接影响模型对**变量间相关性的学习效果**
- MTS 中具有**强相关性**的变量在热力图中做**空间相邻排列**

### (3) 频谱图（Spectrogram）

**适配时序类型:** UTS

**生成频谱图的三种核心方法：**
1. **短时傅里叶变换（STFT）**：基础方法
2. **小波变换（Wavelet Transform）**：对 STFT 的优化，解决了 STFT「窗口大小固定」的缺陷，能更精准提取低频信息
3. **滤波器组（Filterbank）**：音频信号专用的频谱图生成方法


**优势：**
- 编码**时频空间**信息，捕捉时序的频率变化规律

**局限性：**
- 需合理选择窗口 / 小波函数
- 时序恢复方法未成熟

### (4) 格拉姆角场（GAF）

**适配时序类型:** UTS

GAF 分为两种：**GASF** 和 **GADF**

- 步骤：归一化 → 极坐标映射 → 三角函数运算 → 矩阵可视化
- 原始 UTS 的**数值归一化**（核心预处理）：每个时间步的数值 xt 缩放到 [0,1] 或 [-1,1] 区间

**优势：**
- 时间序列恢复能力强
- 可以捕捉 UTS 的**时间相关性和长期依赖**

**局限性：**
- 仅支持 UTS，无直接 MTS 适配方案
- 时间 / 空间复杂度为 O(T²)，长时序建模成本高

### (5) 递归图（RP）

**适配时序类型:** UTS

**生成步骤：**
1. **相空间重构**：将一维 UTS 转化为高维状态向量（时间延迟嵌入）
$$v_t = \left[ x_t, x_{t+\tau}, x_{t+2\tau}, \dots, x_{t+(m-1)\tau} \right] \in \mathbb{R}^m$$

3. **两两距离计算**：计算任意两个向量 vi 和 vj 的距离
4. **阈值化生成图像**：通过阈值判断将距离矩阵转化为二值图像


**优势：**
- 通过调整超参数（相空间维度 m、时间延迟 τ）改变 RP 图像的尺寸
- 捕捉时序的**周期重复模式**和**动态变化特征**

**局限性：**
- 阈值化导致信息损失

## 四、预处理

**时间序列归一化**：对原始时间序列所做的标准化处理

- **折线图（Line Plot）**：核心保证纵轴数值范围合理，① 对时序做缩放重映射 ② 移除时序中的极端值
- **热力图（Heatmap）**：因直接基于原始时序数值成像，采用实例归一化
- **频谱图（Spectrogram）**：均值 / 标准差可控的标准化
- **格拉姆角场（GAF）**：强制要求最小 - 最大归一化，GAF 需将时序值映射到 [0,1]（或 [-1,1]）后做反余弦极坐标变换
- **递归图（RP）**：无需归一化

---

## 五、后处理

**时间序列恢复**：将视觉模型预测的图像像素值还原为原始时间序列数值

- **折线图（Line Plot）**：恢复难度高，需先定位表征时序的像素位置，再通过映射函数还原为原始数值；仅**网格型折线图**可实现有效恢复
- **热力图（Heatmap）**：恢复最简单、最直接，因像素值与时序数值是一对一直接映射
- **频谱图（Spectrogram）**：目前无有效方法
- **格拉姆角场（GAF）**：恢复精准、有固定方法，成像过程是可逆的
- **递归图（RP）**：几乎无法恢复，阈值化操作会不可逆丢失原始时序数值信息，需搭配专用预测头输出时序值
